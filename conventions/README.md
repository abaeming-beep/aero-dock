# 디자인 관행

이 포크의 UI를 고치기 전에 읽는다. 원본 Aero Dock의 Frutiger Aero 디자인을 걷어낸 뒤의 규칙이다.

읽는 순서:

1. [design.md](design.md): 토큰, 레이아웃, 금지 목록
2. [copy.md](copy.md): 문구 규칙, 용어집
3. [icons.md](icons.md): 아이콘 출처와 용도
4. [worklog.md](worklog.md): 무엇을 왜 바꿨는지, 남은 일

`README.md`, `CONTRIBUTING.md`, `docs/ARCHITECTURE.md`는 원본 그대로라 유리 효과, PixiJS, 검색 등 삭제된 기능을 설명한다. 충돌하면 이 폴더를 따른다.

# 문구

모든 문구는 사전에 둔다. 웹 UI는 `src/i18n/ko.ts`, 트레이와 창 제목은 `src-tauri/src/i18n.rs`. 값이 들어가는 문구는 함수로 만들어 타입체크가 인자 누락을 잡게 한다.

## 규칙

- 이모지와 em dash를 쓰지 않는다. 확인: `rg -n "[\x{2014}\x{1F300}-\x{1FAFF}\x{2600}-\x{27BF}]" src/i18n src-tauri/src/i18n.rs`
- 부제, 태그라인, 환영 문구를 쓰지 않는다.
- 라벨은 짧은 명사구. 설명은 `?`에 넣는다.
- 오류는 무슨 일이 일어났는지와, 할 일이 있으면 할 일을 쓴다. 형식은 `...하지 못했습니다`.
- 완료 알림은 `...했습니다.`로 끝낸다.
- 말줄임표로 다음 화면을 암시하지 않는다. 트레이의 `설정…`만 Windows 메뉴 관행을 따른다.

## 번역하지 않은 것

Rust의 기술 오류(예: `path not found`)는 영어로 남아 있으며 토스트에서 한국어 문장 뒤에 붙는다.

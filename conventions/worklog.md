# 작업 기록

## 2026-10-31: 원본 v1.3.2에서 개조

**날씨 효과와 파티클 제거.** `engine/effects`, `ambientStore.ts`, `pixi.js`, 관련 설정을 지웠다. 클릭 물결과 실행 효과도 같이 사라졌다. `asleep`은 메모리 절약 모드에도 쓰여서 `DockBar` 내부 상태로 옮겼다.

**독 버튼 제거.** 찾기, 네트워크, 음소거 버튼을 지웠다. 검색은 그 버튼으로만 열렸으므로 `features/search`와 설정 토글도 지웠다. 앱별 음소거와 볼륨은 유지했다.

**한글화.** 문구를 `src/i18n/ko.ts`와 `src-tauri/src/i18n.rs`로 모았다.

**디자인 교체.** 유리 재질(`surfaces.css`, `engine/glass`), 색상 테마 6종, 재질과 빛 관련 설정을 지웠다. 라이트, 다크, 시스템 테마와 강조색으로 바꿨다. 설정 창을 사이드바 구조로 바꿨다.

사용자 승인 없이 정해서 명세로 확인받은 것: 후원 링크 제거, 색상 테마 폐지, 모드 아이콘의 이모지 교체.

명세에 없어 구현 중 정한 것:

- 기본 창 폭을 820에서 900px로 늘렸다. 라벨이 나오는 840px 기준보다 좁았다.
- 독 날짜에서 요일을 뺐다. 세로 독 폭을 넘었다. 요일은 시계의 툴팁에 있다.
- 모드 아이콘 선택기의 직접 입력을 지웠다. 이모지 입력 통로였다.
- 오디오 화면의 모드 안내 문단과 "모드 켜기" 링크를 지웠다. 내용은 `?`로 옮겼다.
- 독 불투명도를 패널 배경에만 적용한다. 원본은 아이콘까지 흐려졌다.

**설정 호환.** 이전 설정 파일은 그대로 읽힌다. 없어진 필드는 무시되고 다음 저장 때 사라진다.

## 2026-10-31: TiMe 위젯 추가

VClouds의 Rainmeter 스킨 "TiMe - Digital"을 `TimeWidget.tsx`로 옮겼다. 값은 스킨의 `.ini`와 `UserVariables.inc`에서 가져왔다. 스킨의 라이선스는 CC BY-NC-SA 3.0이고 프로젝트 본체는 MIT이므로, 이 파일과 위 CSS는 비상업 이용과 동일 조건 공유 조건을 따른다.

- 블러는 옮기지 않았다.
- Century Gothic 파일은 저장소에 넣지 않고 시스템에 설치된 글꼴을 쓴다. 없는 PC에서는 Segoe UI로 대체된다.
- 글꼴에 한글이 없어 요일과 월은 원본처럼 영문 대문자다.
- 시간은 스킨 기본값인 24시간제다.

## 2026-10-31: AB Dock으로 이름 변경, 아이콘 교체

화면에 보이는 이름을 AB Dock으로 바꿨다. 식별자 `com.aerodock.desktop`은 그대로다. 바꾸면 설정 폴더가 달라져 기존 설정을 찾지 못한다. `aero-dock` 패키지 이름, `aero-` 클래스 이름, 창 클래스 이름, `LICENSE`의 원작자 고지와 `publisher`, `copyright`도 유지했다.

앱 아이콘은 사용자의 SD 캐릭터 이미지로 만들었다(`src-tauri/icons/`, 생성: `pnpm tauri icon`). 원본의 여백을 잘라 정사각형에 맞췄다. 이 이미지는 사용자가 제공한 것으로 프로젝트의 MIT 라이선스 대상이 아니다.

## 남은 일

- `pnpm install`이 esbuild 빌드 스크립트 미승인으로 exit 1을 낸다. pnpm 12가 `package.json`의 `pnpm` 필드를 읽지 않아서다. 실행과 빌드에는 지장이 없다.
- Rust의 검색용 명령(`list_apps`, 최근 파일)과 `setDockFocusable`은 남아 있다. 쓰이지 않는다.
- `README.md`와 `docs/`는 원본 설명 그대로다.
- Rust의 기술 오류 문구는 영어다.
